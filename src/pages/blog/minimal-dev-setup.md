A year ago, my development setup was a maze. Multiple IDEs, dozens of extensions, a terminal customized beyond recognition, and a dotfiles repo that would take an afternoon to set up on a new machine.

Then my laptop died.

## The forced reset

When I set up my new machine, I decided to start from zero. Instead of restoring my old setup, I'd only install things as I actually needed them.

Here's what I ended up with:

- **Editor**: VS Code with five extensions (not fifty)
- **Terminal**: The default terminal with a clean prompt
- **Font**: One monospace font, one size
- **Tools**: Git, Node, Python. That's it to start.

## What I learned

Most of what I had before was accumulation, not intention. Extensions I installed for one project and never removed. Terminal themes I spent hours configuring but didn't actually make me faster.

The minimal setup taught me something important: **every tool has a cognitive cost**. Even if you're not actively thinking about it, visual clutter and unnecessary options create friction.

## The three-day rule

Now I follow a simple rule: when I think I need a new tool or extension, I wait three days. If I still need it after three days of working without it, I install it. If not, the urge passes.

About 80% of the time, the urge passes.

## What matters

- Fast startup time
- Instant file switching
- Good search
- A clean, readable font

Everything else is a nice-to-have. And nice-to-haves have a cost that's easy to underestimate.

> The best setup is the one you don't think about.
