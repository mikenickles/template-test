# Timberbot

A browser-playable 3D harvesting-and-building game set in a golden-hour forest. You drive **Timberbot**, a 1.6 m weathered
forestry robot, around a 150 × 150 m valley: chop trees, mine mossy boulders, and build a palisade, a campfire and a stone
beacon.

Everything on screen was generated by the scripts in `pipeline/` — there are no third-party art assets and no CDN
dependencies. Three.js r181 is vendored in `vendor/`.

## Play without installing anything

`python3 tools/build_single.py` (from `timberbot/`) packs the whole game into one file, `dist/timberbot.html`
(about 13 MB). Double-click it to play; it needs no server and no internet. It uses Node's `npx` to fetch esbuild
and Pillow to shrink a few textures.

## Run

Any static file server works (ES modules need `http://`, not `file://`).

```bash
cd timberbot
node serve.mjs            # http://localhost:8080/   (zero dependencies)
# or: python3 -m http.server 8080
```

From the repository root you can also use `npm run game`.

URL options: `?quality=0|1|2` locks the graphics level (default: 2, auto-steps down if the frame rate stays under 30),
`?qa` opens the diagnostics overlay, `?autostart` skips the start screen (no audio until the first input),
`?grass=0.1` scales grass density (useful on software renderers).

## Controls

| Input | Action |
| --- | --- |
| `W` `A` `S` `D` / arrow keys | Move at 6 m/s, strictly camera-relative |
| Mouse drag, `Q` / `E` | Orbit the camera 360° |
| Scroll wheel | Zoom 5 – 20 m (default 10 m) |
| `Space` / left-click | Harvest the nearest tree or boulder within 3.5 m |
| `1` `2` `3` or the HUD buttons | Timber Wall · Campfire · Stone Beacon |
| Left-click | Place the ghost (green = valid, red = blocked / too steep / too poor) |
| `R` / `Shift+R` | Rotate the ghost 15° |
| Right-click / `Esc` | Cancel build mode |
| `T` | QA diagnostics overlay |
| `M` | Mute |
| `H` | Hide the controls card |

On a phone or tablet the controls are gestures (`src/touch.js`):

| Gesture | Action |
| --- | --- |
| Thumb anywhere on the left side | A faint stick appears under it; push further to walk faster |
| Drag on the right side | Look around |
| Pinch | Zoom 5 – 20 m |
| Tap | Harvest (tap a tree or boulder, or anywhere to hit the nearest one) |
| Tap a build icon, drag, lift | Aim the ghost just above your fingertip, lift to place; a second-finger tap rotates it |

## Rules

| | |
| --- | --- |
| Tree | 3 hits, +1 Wood per hit, shrinks and shakes each hit, topples on the third |
| Boulder | 3 hits, +1 Stone per hit, chips each hit, crumbles on the third |
| Timber Wall | 3.0 m wide × 2.5 m tall · 3 Wood · blocks movement |
| Campfire | 1.5 m diameter · 2 Wood + 3 Stone · flickering shadow-casting point light, flames, smoke |
| Stone Beacon | 3 × 3 m base, 7 m tall · 4 Wood + 6 Stone · glowing brazier |

## World

- Heightfield terrain, exactly 150 × 150 m, 0 – 8 m elevation inside the 120 × 120 m playable area.
- 20 m spawn clearing at the origin (elevation < 1.5 m, no trees or boulders).
- The outer 15 m rises into a rocky ridge packed with ~340 trees, 90 crags and undergrowth.
- 136 harvestable trees (78 conifers, 58 broadleaf and birch; 6 – 14 m) and 50 mossy boulders (1 – 3 m).
- ~78,000 instanced grass tufts, 520 ferns, 14 fallen logs, bushes, wildflower patches and 1,400 drifting pollen motes.

All of these constants live in `src/config.js`, and the in-game QA overlay re-measures them live.

## Layout

```
index.html, style.css     page shell + HUD
src/                      game code (ES modules, no build step)
  config.js               every spec measurement in one place
  terrain.js              seeded heightfield, exact height queries, heightfield ray-march
  assets.js               loaders, PBR material library, shader patches (wind, terrain splat, moss)
  world.js                scatter, chunked instancing, grass, splat/contact-AO map
  env.js                  sky dome, sun + fitted shadow frustum, IBL, post-processing
  robot.js                procedural animation of the articulated robot
  game.js                 input, movement + collision, camera, harvesting, building
  fx.js                   particles, fire, floating text, pooled lights
  audio.js                synthesised Web Audio soundscape and SFX
  hud.js, qa.js           HUD and the diagnostics overlay
assets/models/*.glb       exported from Blender
assets/textures/*.webp    procedural + baked PBR maps
pipeline/                 the asset sources (see below)
qa/playtest.mjs           Playwright play-through with assertions + screenshots
vendor/three/             Three.js r181 (MIT)
```

## Asset pipeline

```bash
pip install -r pipeline/requirements.txt     # bpy (Blender as a Python module), numpy, Pillow
pipeline/build_all.sh                        # ~15 min on 4 CPU cores, mostly Cycles bakes
```

| Script | Output |
| --- | --- |
| `textures.py` | Tileable PBR sets (albedo / normal / AO-roughness-height) from periodic noise: barks, ground, cliff, masonry, shingles, timber, charcoal |
| `build_foliage.py` | Models real leaves, needle sprays and a fern frond, then renders them orthographically in Cycles into albedo+alpha and normal atlases |
| `build_trees.py` | Conifers, broadleaf trees, birch, bush, fern, fallen log; vertex colours carry baked AO and wind weights |
| `build_rocks.py` | Sculpts a high-poly boulder, decimates it, and bakes albedo / normal / AO / roughness from the high-poly and a procedural rock + moss shader |
| `build_structures.py` | Palisade, campfire and beacon, asserted against the gameplay dimensions |
| `build_robot.py` | Timberbot: bevelled hard-surface parts in a joint hierarchy, one UV atlas, baked weathering (brushed steel, chipped paint, edge wear, grime) |

## QA

Press `T` in game for live FPS, player coordinates, WebGL status and 16 automated checks (map size, elevation range, spawn
clearing, densities, structure sizes and costs, shadow setup, terrain grounding, collision integrity, camera-relative
movement, cursor ray-cast accuracy, inventory ledger).

The scripted play-through drives real keyboard and mouse input and writes screenshots plus `report.json`:

```bash
node serve.mjs 8123 &
node qa/playtest.mjs qa/out 2                                        # needs Playwright; args: output dir, quality level
PT_SIZE=640x360 node qa/playtest.mjs qa/out 0 http://localhost:8123/ grass=0.04   # fast variant for software GL (no GPU)
node qa/touchtest.mjs qa/out                                         # phone controls in an emulated 390 x 844 touchscreen
node qa/screenshots.mjs qa/out spawn,forest,camp 2                   # camera presets for visual review
```
